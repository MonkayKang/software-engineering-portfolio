## T-Shirt and Prioritize User Stories
### Story 1 — View weekly timetable
As a student, I want to view my personal weekly timetable, so that I can plan my study and personal commitments.
Acceptance criteria
1. Given a student is logged in, when they open their timetable, then the system displays the classes assigned to them for the selected week.
2. Each class displays its date, start time, end time, module and location.
3. When the student selects another week, the timetable updates to show that week's classes.
4. If no classes are scheduled for the selected week, the system displays a clear message indicating that there are no scheduled classes.

### Story 2 
As a student, I want to see room and lecturer details for each class so I know which classroom each of my class is in.

### Story 3
As a student, I want to receive notification when a class is rescheduled or cancelled, so that I don't come to school for no reason

### Story 4
As a lecturer, I want to swap into an alternative lab/tutorial slot when my assigned 
one clashes with another commitment, so that I can continue teaching without having complications

### Story 5
As student, I want to export my timetable to my phone's calendar app, so that I can always check when my classes are and that they are easily accessible. 

###  Story 6 — Cancel or relocate a class
As a lecturer, I want to mark a class as cancelled or relocated, so that students receive accurate information about their classes.
Acceptance criteria
1. Given an authorised lecturer selects a class, they can mark it as cancelled or update its room location.
2. When a class is cancelled, its status is updated and affected students are notified.
3. When a class is relocated, the new room appears on the affected students' timetables and they receive a notification.
4. Unauthorised users cannot change the class status or location.
